What is being compared?

  • Browser: built-in OS/browser voice; may itself use a remote service.
  • Kitten: 15M-parameter Nano int8, ONNX Runtime Web, browser cache.
  • Pocket 18M: independently maintained ONNX worker using WASM, streaming PCM.
  • Pocket 7M: intentionally marked experimental until a compatible export is supplied. No fake fallback.
  • Kokoro: 82M model, quantized q8, local WASM inference.
  • Piper: VITS model downloaded separately per selected voice.
  • Spellophone: eSpeak NG through WASM, very compact and robust, but more robotic than neural voices.
Dependencies, attribution & limitations

All synthesis for the five neural engines is client-side, using on-demand code and model downloads. The web page itself has no backend, npm, build step or bundled weights. Browser TTS may be cloud-backed depending on voice. Hugging Face or CDN failures, COOP/COEP/thread restrictions, unsupported WebAssembly/WebGPU, memory pressure and browser autoplay policies can prevent execution, especially on iOS. Keep this tab foregrounded during heavy synthesis.
